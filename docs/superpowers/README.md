# Especificaciones en ruta heredada

Este directorio conserva especificaciones que código y tests aún citan mediante su ruta
histórica `docs/superpowers/specs/`. No requiere el plugin ni el método que originó el
nombre.

La clasificación, vigencia y relación de reemplazo se mantienen únicamente en el
[índice de especificaciones](../specs/README.md). No agregues planes, prompts ni
artefactos de sesión a esta carpeta.
