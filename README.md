# OpForja

Modelador web de OPM/ISO 19450 con edición bimodal OPD/OPL, persistencia y generación
reproducible de bundles. La aplicación vive en `app/`; los modelos de dominio viven en
sus repositorios propietarios.

Para desarrollo, empieza por `AGENTS.md` y `docs/README.md`. Los comandos y gates reales
se resuelven desde `app/package.json`.
